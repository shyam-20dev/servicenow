# Laptop Running Slowly - Performance Troubleshooting

Applies to: company Windows 11 laptops.

## Quick checks
1. Restart the laptop. Laptops that have not been restarted for more than 7 days are the most common cause of slowness.
2. Save your work and close applications and browser tabs you are not using. Browsers with dozens of tabs can use several gigabytes of memory.
3. Check free disk space: open File Explorer, This PC. Less than 10 percent free space slows the whole system. Remove old downloads and empty the Recycle Bin.

## Find what is using resources
Press Ctrl + Shift + Esc to open Task Manager. Sort by CPU, Memory and Disk. If one application uses most resources, close it or restart it. If the Startup tab shows many enabled apps, disable the ones you do not need at boot.

## Updates and malware
Install pending Windows updates from Settings, Windows Update, and restart. A laptop that is slow right after an update may still be finishing background tasks. Run a full scan with the company security software if you suspect malware.

## Overheating and loud fan
A loud fan and hot case suggest dust or blocked vents. Use the laptop on a hard flat surface, not on a bed or sofa. If the fan stays loud while idle, raise a Hardware incident.

## Hardware upgrade
Laptops older than four years or with 8 GB of memory or less may need replacement. Submit a hardware request through the service catalog or raise an incident if the laptop is unusable for work.
